# 项目规范文档

本文档定义了 `theme-sky-blog-2` 项目的开发规范、技术栈和最佳实践。

## 1. 技术栈概览

- **构建工具**: Vite 8
- **CSS 框架**: Tailwind CSS v4.1+
- **JavaScript 框架**: Alpine.js v3.15+
- **语言**: TypeScript
- **页面交互**: Swup 4（保留终端外壳的局部导航）
- **性能优化**: 原生图片懒加载
- **代码规范**: ESLint + Prettier

## 2. 目录结构规范

```
theme-sky-blog-2/
├── src/                # 源码目录
│   ├── main.ts         # 入口文件 (引入样式、初始化插件)
│   ├── styles/         # 样式文件
│   │   ├── main.css    # 全局自定义样式 & 动画
│   │   └── tailwind.css# Tailwind 入口
│   └── vite-env.d.ts   # 类型声明
├── templates/          # Halo 主题模板 (Thymeleaf)
│   ├── assets/         # 编译产出目录 (Git 需提交)
│   ├── modules/        # 页面组件/片段
│   │   └── layout.html # 全局布局 (包含 Swup 容器 #main)
│   ├── index.html      # 首页模板
│   └── post.html       # 文章页模板
├── theme.yaml          # 主题元数据配置
├── settings.yaml       # 主题后台配置项
└── package.json        # 依赖管理
```

## 3. 开发规范

### 3.1 命名规范

- **文件/文件夹**: 使用 `kebab-case` (如 `post-card.html`, `user-profile/`)。
- **CSS 类名**: 优先使用 Tailwind Utility Class。自定义类使用 `kebab-case`。
- **JS 变量/函数**: 使用 `camelCase`。
- **TS 接口/类型**: 使用 `PascalCase` (如 `DemoStore`)。

### 3.2 页面交互

- `src/common/navigation.ts` 负责 Swup 导航，`src/common/runtime.ts` 在替换正文后初始化 Alpine 及兼容的插件生命周期。
- 文章计数、认证或独立插件布局需要完整页面生命周期时，使用原生链接并明确跳转策略。
- `pjax:complete` 是提供给现有插件的兼容事件。主题自己的页面初始化使用 `theme:page-ready`。

### 3.3 样式开发

- 优先使用 Tailwind CSS 类。
- 复杂的自定义动画或组件样式写在 `src/styles/main.css` 中。
- 响应式设计：必须适配移动端，使用 Tailwind 的 `md:`, `lg:` 等前缀。

### 3.4 模板开发 (Thymeleaf)

- 公共前台页面使用 `modules/layout.html`，主内容放在 `#main`。认证、错误页和插件页面使用各自的布局契约。
- 共用的列表行、分页及空态使用模板片段。保留服务端渲染的可访问链接。
- 静态资源引用使用 `modules/runtime-assets.html`，文件由 Vite 生成并携带版本和内容修订号。

### 3.5 懒加载

- 首屏之外的图片使用 `src` 和原生 `loading="lazy"`，并提供准确的 `alt`。
- 已有的 `img.lozad[data-src]` 内容会在主题挂载时转成原生懒加载。

## 4. Git 提交规范

遵循 Conventional Commits 规范：

- `feat`: 新功能
- `fix`: 修复 Bug
- `docs`: 文档变更
- `style`: 代码格式调整（不影响逻辑）
- `refactor`: 代码重构
- `chore`: 构建过程或辅助工具的变动

示例: `feat: 集成 NProgress 进度条`

## 5. 版本发布

1. 更新 `package.json` 版本号。
2. 更新 `theme.yaml` 版本号。
3. 执行 `pnpm build` 生成最新资源。
4. 提交所有更改（包括 `templates/assets/`）。
