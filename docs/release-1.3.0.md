# 1.3.0

## 新增

- 后台可切换经典文件表和 Unix 长列表，默认使用经典文件表。布局和终端配色独立设置。
- 手机阅读页可按需展开目录和终端工具。

## 修改

- 站内局部导航改用 Swup 4，改善切页过渡、浏览器前进后退和阅读位置恢复。
- 统一公开模板的宽度与留白，修复终端焦点、文章返回、阅读进度和文件树标记。
- 认证页使用独立版式和共享配色，修复 ALTCHA 资源 404、Passkey 直达登录、注册协议及密码重置反馈。

## 删除

- 移除旧的局部切页实现、未使用的 `lozad` 依赖和旧版 ALTCHA 脚本引用。

## 其他

- 最低支持 Halo 2.27.0。保留评论与 Shiki 使用的插件导航兼容接口。
- 补充导航、阅读页和认证回归检查。
