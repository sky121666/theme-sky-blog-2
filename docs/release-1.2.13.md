# 1.2.13

本次改善新版 Halo 与已集成插件的兼容性，修复评论固定链接及主题预览跳转。

- 修复重复打开同一评论或回复链接时定位不准确的问题，保留已挂载评论组件与输入状态。
- 搜索结果和主题命令的同源跳转保留预览主题，避免意外切换到当前启用主题。
- 改善评论按钮文字对比度，修复超链接卡片被插件默认暗色样式覆盖的问题。
- 对齐 Halo 认证布局与动态登录片段契约，更新认证资源版本参数，修复第三方登录的“记住我”同步。
- 更新 Vite 及受影响的构建、打包和检查依赖，修复依赖审计发现，并补充文件匹配兼容性回归测试。

**兼容范围变更：主题最低要求由 Halo 2.26.0 提高到 Halo 2.27.0。** 1.2.13 以本轮最新版已适配插件组合为支持基线，其中 Comment 3.5 自身要求 Halo 2.27.0。使用 Halo 2.26 的站点需先升级 Halo，再升级至本主题版本；即使未启用评论插件，主题最低要求也统一为 2.27.0。本次实际验证环境为 **Halo 2.27.2、Comment 3.5.0、Search 1.8.0**。

搜索预览参数保留依赖浏览器 Navigation API，不支持时沿用插件原始跳转；不影响普通站点搜索。

本次覆盖主题已有集成，不扩展为全部已安装插件的完整功能适配。
